# Guia de introdução à inflação

Este guia é uma introdução à inflação para estudantes de Economia e para quem quer entender por que os preços sobem.

A ideia surgiu porque inflação aparece em quase toda disciplina do curso, mas muita gente (eu incluído, no começo) decora a definição sem entender direito como ela é medida ou por que o Banco Central mexe nos juros por causa dela.

## Objetivo

Ao final, o leitor será capaz de explicar o que é inflação e quais são suas principais causas, entender como o IPCA e outros índices são calculados, diferenciar inflação mensal de acumulada e compreender como o Banco Central usa a taxa Selic para controlar os preços.

## Público-alvo

Estudantes dos primeiros semestres de Ciências Econômicas, ou qualquer pessoa curiosa sobre o assunto.

## Pré-requisitos

Só é preciso saber calcular porcentagem. Uma calculadora (a do celular serve) ajuda nos exercícios e no exemplo resolvido.

## Como navegar

Leia as seções na ordem. Cada uma termina com uma pergunta rápida, e a resposta fica escondida: clique em "Ver resposta" só depois de pensar um pouco. Os exercícios funcionam do mesmo jeito. No fim de cada página há links para a seção anterior, a próxima e o início.
